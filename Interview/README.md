## What is Dynatrace, and dose it contribute to performance engineering?

- Dynatrace is an application Performance Monitoring (APM) tool.
- It aids in monitoring and analyzing application and service performance.
- It offers real-time insights into different aspects of application behavior.
- Provides data on user experience, server response times, and transaction traces.
- In performance engineering, Dynatrace helps:
  - Identify bottlenecks within the applications.
  - Optimize the utilization of resources.
  - Ensure overall application efficiency

## What is OneAgent in Dynatrace?

- OneAgent is the core component installed on hosts that automatically discovers all processes, services, and dependencies.

## SmartScape

- It's a real-time topology map showing dependencies between services, processes, and infrastructure.

## Different between RUM and Synthetic Monitoring

- RUM captures data from user interactions. Synthetic Monitoring uses scripts to simulate user interactions.

## How dose Dynatrace auto-discover services

- OneAgent uses deep code instrumentation and network sniffing to detect services, technologies, frameworks, and dependencies.

## What is Monaco in Dynatrace?

- Monoco (Monitoring as Code) allows configuration using YAML/JSON files through the Dynatrace Configuration aoi.

## How do you create a custom alerting rule?

- Using alerting profiles you filter by severity, tags, event types, and assign to notification channel.

## Explain the key features of Dynatrace that aid in performance testing and optimization.

- Dynatrace offers the following features:
  - Real user Monitoring (RUM)
  - Synthetic Monitoring
  - Infrastructure Monitoring
- Real User Monitoring(RUM)
  - Captures real user interactions
  - Aids in understanding user experience.
- Synthetic Monitoring:
  - Simulates user interactions.
  - Proactively detects performance issues
- Infrastructure Monitoring:
  - Provides insights into underlying infrastructure's health
  - Helps diagnose server-related problems
